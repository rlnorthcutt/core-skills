Difficulty tiers

Easy — drop in: prompt-only skill records; write JSON, install, verify. No new dependencies.

Involved — some work: need supporting libraries installed, file-output workflows, and render-verification steps before they're reliable.

Complex — recreate: worth having but must be rebuilt around Omnideck's runtime (custom apps, interactive artifacts) rather than ported from source material.

Wave 1 — Quick wins

Improve

improve
InvolvedHigh value

Reflects on the current conversation — what worked, what didn't — and turns lessons into concrete artifacts: a new skill, a custom tool, edits to existing skills/tools, a custom app, or an agent profile.

Value: closes the feedback loop between sessions and system setup; every friction point becomes a permanent improvement instead of a repeated cost.

Skill Creator

skill-creator
EasyHigh value

Creates high-quality, well-scoped skills: gathers requirements, drafts the skill record, validates naming and trigger clarity, installs, verifies it loads.

Value: meta-capability — lets users teach the system new procedures themselves; every other skill in this plan gets easier once this exists.

Docs Writer

write-docs
EasyHigh value

Writes and maintains technical documentation — READMEs, how-tos, API references, architecture notes, changelogs — verified against the actual code.

Value: docs are universally needed and universally stale; verification-against-code is the differentiator between this and generic doc generation.

Humanize Content

humanize-text
EasyHigh value

Removes AI tells and patterns from writing — em-dash density, "delve" verbs, rule-of-three lists, hollow intensifiers, perfect parallelism, summary performances.

Value: immediate, visible quality gain on any user-facing text; high-frequency request once available.

Learning

learning-planner
EasyHigh value

Builds spaced-repetition learning plans: dependency-ordered topic maps, schedules fitted to real weekly budgets, atomic flashcards, curated resources, review cadence.

Value: turns "I want to learn X" into an operable plan; spaced repetition is the evidence-based core, not a garnish.

Writing Blocks

write-drafts
EasyHigh value

Composes messages, emails, posts, and bios — register-matched, one ask per draft, purpose in line one, unknowns marked rather than invented.

Value: highest-frequency writing surface; done well it replaces most ad-hoc drafting requests.

Wave 2 — Office & media

Presentations

make-slides
InvolvedHigh value

Creates and edits PowerPoint / Google Slides decks — story-first structure, assertion headlines, speaker notes, render-verified output.

Work: python-pptx pipeline + slide-image verification pass. Value: high-frequency deliverable; correctness of rendering is what makes it trustworthy.

Spreadsheets

make-sheets
InvolvedHigh value

Creates, edits, analyzes, and charts Excel / CSV / Google Sheets data — type-safe data models, formula-first, chart-to-question matching.

Work: openpyxl + round-trip verification. Value: data work is a top use case; the analysis hygiene is the differentiator.

Documents

make-docs
InvolvedHigh value

Creates and edits Word-style documents — style-based structure, outline-first, preserved heading hierarchy on edit.

Work: python-docx + render check. Value: the structured-editing discipline (styles over manual formatting) is what separates it from raw generation.

PDF

make-pdfs
InvolvedHigh value

Reads, creates, modifies, and visually verifies PDFs — extraction with the right tool per document type, source-format rendering, image-level verification.

Work: poppler/weasyprint/pdfplumber toolchain + verify loop. Value: PDFs are where silent failures live; the verification step is the whole point.

Image Generation

image-generation
EasyMedium value

Generates and edits images — grants the existing image_generation category and adds the prompt craft: style control, iteration, composition direction.

Value: plumbing exists; this makes output quality deliberate rather than accidental.

Wave 3 — Creators & research

Tool Creator

tool-creator
InvolvedHigh value

Creates custom tools — parameterized, reusable operations registered for discovery, with typed parameters and least-privilege scope.

Value: turns one-off scripting into permanent capability; pairs with skill-creator as the other half of "teach the system to do this."

Agent Creator

agent-creator
EasyMedium value

Creates agent profiles — persona, minimal skill grants, system prompt teaching the essentials, right default model.

Value: packages recurring setups into reusable starting points.

Visualize

visualize
ComplexHigh value

Builds interactive diagrams, simulations, graphs, and mockups — single-file HTML artifacts with parameter controls and live output.

Work: needs an interactive-artifact runtime decision before it's reliable. Value: highest-ceiling skill in the plan — mechanisms you can manipulate, not just view.

App Creator

app-creator
ComplexHigh value

Creates and manages custom apps — manifest, frontend, optional actions, data persistence, served from the apps directory.

Work: full custom-app lifecycle; depends on the same runtime decisions as visualize. Value: the "build me a tool I can open" end of the spectrum.

Research

research
EasyHigh value

Multi-source research over existing browser/webfetch tools — question refinement, source triangulation, synthesis with provenance.

Value: the workflow already exists implicitly; making it a skill makes it consistent and citable.
