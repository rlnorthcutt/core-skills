# plan-learning T1 — Baseline (no skill)

Task: "I want to learn Rust. I have about 4 hours a week and want to build a small CLI tool I can actually use (log parsing, like my logscan project but in Rust). 3-month horizon."

## Rust Learning Plan (4h/week, 3 months)

### Week 1-2: Basics
- Install Rust via rustup
- Learn variables, types, control flow
- Functions and modules

### Week 3-4: Ownership & Borrowing
- Ownership rules
- References and borrowing
- Common patterns

### Week 5-6: Structs, Enums, Traits
- Define structs and enums
- Implement traits
- Error handling with Result

### Week 7-8: CLI + File I/O
- Read files
- Parse lines
- Build a basic CLI

### Week 9-10: Testing
- Write unit tests
- Integration tests

### Week 11-12: Polish
- Error handling
- Documentation
- Final project

### Resources
- The Rust Book (official)
- Rust by Example
- Rustlings

### Goal
Build a working log-parsing CLI tool in Rust.
