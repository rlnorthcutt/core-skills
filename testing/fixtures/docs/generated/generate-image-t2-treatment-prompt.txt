ROUTED TO SVG/CODE, NOT image generation. Reasoning:
- Icons are a PRECISE, REPEATABLE graphic set: 6 glyphs must share identical stroke weight, corner radius, optical alignment, and grid. A bitmap generator cannot hold that consistency across a set — each icon is generated independently and will drift in stroke thickness, size, and alignment.

- The set must be a coherent family (same visual language). Image generation gives "6 similar but not identical" icons; SVG gives one shared grid + stroke spec applied uniformly.
- Deliverable is code, which is versionable, scalable (any size), and themeable (stroke color via CSS) — none of which a raster gives.
